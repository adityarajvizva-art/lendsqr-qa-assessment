# Lendsqr QA Assessment

## Overview

This repository contains the QA assessment deliverables for the Adjutor platform.

## Scope Covered

### Functional Testing

* Signup flow validation
* KYC workflow testing
* App creation workflow
* API key generation
* Nigerian Validation APIs

### API Testing

* Automated Postman test collection
* Positive and negative test scenarios
* Response validation
* Status code validation
* Performance observations

### Defect Reporting

* Functional defects
* API validation defects
* Documentation observations
* UI/UX findings

### Deliverables

| Folder               | Contents                           |
| -------------------- | ---------------------------------- |
| postman              | Postman collection and environment |
| test-cases           | Manual and API test cases          |
| defects              | Defect reports and observations    |
| performance-analysis | API response time observations     |
| security-review      | Security assessment findings       |
| screenshots          | Evidence and execution screenshots |
| reports              | Final assessment summary           |

## Tools Used

* Postman
* GitHub
* Notion
* Chrome Browser
